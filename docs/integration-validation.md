# V3 与架构优化集成验证

本次集成以 `main` 为基础，合入 `chore/v3-team-release` 与
`feature/campusbuddy-architecture-optimization`，并修复发现页请求乱序和身份弹窗键盘操作。

## 集成处理

- 同时保留上传体积超限的 413 响应和 PostgreSQL 锁超时的 503 响应。
- V3 活动详情包含 `favorited`，对应额外一次收藏查询；详情访问测试仍检查受保护字段和避免加载整组成员。
- 群消息增加一次通知和投递任务，幂等重放及置顶更新不得产生重复通知。
- V3 注销会删除该用户既有通知、投递和幂等记录。并发测试分别核对其他用户新增记录，以及注销和业务操作先后顺序下注销用户的剩余记录；继续检查锁顺序、无死锁和业务效果仅提交一次。

## 前端修复

- 仅最新搜索请求能更新活动列表、分页游标、收藏状态、错误和加载状态；切换筛选后旧分页不能追加到新结果。
- 身份弹窗打开后焦点进入弹窗，Tab/Shift+Tab 在弹窗内循环，Esc 关闭并恢复触发控件焦点。背景区域不可交互，活动详情触发身份弹窗时保持正确叠层。

## 复现命令

先按项目运行说明配置本地环境，启动数据库。集成测试只使用独立的
`campus_buddy_mvp2_test` 数据库，现有并发测试还校验服务实际位于回环地址的 5432 端口。
不要把测试连接配置为演示或生产数据库。

```powershell
. ./scripts/env.ps1
# 限制缓存的 Spring 测试上下文，避免多个连接池占满默认数据库连接数。
./mvnw.cmd -B '-Dmaven.repo.local=.local/m2' '-Dspring.test.context.cache.maxSize=2' test
npm.cmd --prefix web ci --no-audit --no-fund
npm.cmd --prefix web run build
./mvnw.cmd -B '-Dmaven.repo.local=.local/m2' '-DskipTests' package

# 应用已启动；若使用代理入口，请将 BASE_URL 改为对应本地地址。
$env:BASE_URL='https://localhost:8443'
# 如未安装可直接解析的 playwright 模块，将 PLAYWRIGHT_MODULE 指向本机模块目录。
node ./scripts/ui-regression.mjs
```

新增 UI 回归只读访问应用，并拦截搜索响应模拟乱序，不创建活动。
报告写入忽略目录 `.local/ui-regression.json`。原浏览器烟测脚本会创建演示记录；本次使用临时副本适配独立数据库的连接和输出位置，不改动原脚本的业务断言。

本轮未执行云服务器部署、压力测试或完整浏览器/读屏兼容性验收。演示身份切换仍为现有设计，不代表已具备对公网开放的正式认证能力。
本机配置、数据库备份、证书、密钥及原始运行日志不纳入提交。
